# 📦 Sistema de Inventário de TI

Sistema web para controle e gerenciamento de ativos de Tecnologia da Informação, desenvolvido para otimizar o acompanhamento de equipamentos, colaboradores, atribuições, manutenções e relatórios.

## 🚀 Funcionalidades

- 📋 **Gestão de Equipamentos:** Cadastro, consulta e controle de status de ativos de TI.
- 👥 **Gestão de Colaboradores:** Associação de equipamentos aos respectivos responsáveis.
- 🔄 **Movimentações e Atribuições:** Histórico e registro de entregas e devoluções de dispositivos.
- 🛠️ **Manutenção:** Acompanhamento de chamados e equipamentos em reparo.
- 📊 **Relatórios e Dashboard:** Painel central com métricas gerais do inventário.
- 🌐 **Acesso Remoto:** Integração com Ngrok para acesso global via dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

- **Backend:** Python / Flask
- **Banco de Dados:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript
- **Túnel de Rede:** Ngrok (Acesso público / Mobile)
